2. Дан текст. Найти в нем все адреса ботов мессенджера. Адрес бота вмессенджере начинается с символа @,  
не содержит пробелов, не начинается с цифры и содержит только латинницу и нижнее подчеркивание.  
Не использовать регулярные выражения.  
1)  
Ввод:  Пишите нам: @support_bot или @help_bot для помощи!  
Вывод: Найденные боты (2):  
         @support_bot  
         @help_bot  
3)  
Ввод:  @1badbot @  @_ok_bot @goodBot  
Вывод: Найденные боты (2):  
         @_ok_bot  
         @goodBot  
4)  
Ввод:  Напиши @my_bot_123 или @AnotherBot  
Вывод: Найденные боты (2):  
         @my_bot_123  
         @AnotherBot
